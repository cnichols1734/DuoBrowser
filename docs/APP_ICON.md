# DuoBrowser app icon

The owner-selected artwork is a cyan-to-blue globe inside a white open-book / folding-screen outline, on a dark rounded tile with a white outer surround. It replaces the earlier compass and two-panel D concepts.

Source supplied by the owner on October 27, 2026: `Blue Globe Open Book Icon.png` (1254 × 1254, opaque PNG). The supplied artwork is preserved, including its white outer surround and rounded tile; only its resolution was converted to 1024 × 1024 using macOS sips. No new image generation or creative alteration was performed for this revision.

Asset: `DuoBrowser/Assets.xcassets/AppIcon.appiconset/DuoBrowser-Icon.png`. The AppIcon catalog is included in the target resources and selected in both Debug and Release build settings. Xcode supplies required app-icon renditions and iOS supplies its additional corner mask. This is a raster asset; custom dark/tinted variants are not included. The product demo closing card uses the same asset.
