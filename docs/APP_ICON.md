# DuoBrowser app icon

Two offset panels form a distinctive D: a warm ivory rear panel and a sea-green outlined front panel on graphite. The open-panel silhouette references Duo's expanding display. This replaces the initial compass design, which the owner felt was too close to Safari.

Created with the built-in image-generation tool on October 27, 2026. The opaque square original was exported at 1024 × 1024 using macOS sips for the iOS universal AppIcon asset. Xcode supplies required app-icon renditions and the system supplies the corner mask. This is a raster asset, not a layered Icon Composer document; custom dark/tinted variants are not included.

Asset: `DuoBrowser/Assets.xcassets/AppIcon.appiconset/DuoBrowser-Icon.png`. The AppIcon catalog is included in the target resources and selected in both Debug and Release build settings. The product demo closing card uses this same asset.

## Generation prompt

Create the final app icon for DuoBrowser, a premium minimalist web browser designed around an expanding screen. ONE original symbol only: two offset upright rounded rectangular panels combine into a bold abstract capital D / open doorway. The rear panel is a short solid warm ivory vertical slab on the left; the foreground panel is a larger deep teal D-shaped outline with a flat vertical left spine and a generous smoothly rounded right edge, shifted slightly to the right and upward. They should read as one exceptionally simple, bespoke geometric monogram, not as overlapping documents. A dark near-black graphite background fills the complete square. Restrained three-color palette only: graphite #151D20, warm ivory #F3F0E8, vivid yet sophisticated sea-green #42C9A5. Bold clean weight, rounded precise joins, generous negative space, perfectly optically centered. Symbol occupies approximately 60 percent of square width and 62 percent height, legible at 48 pixels. Flat vector-like graphic design, impeccable professional brand identity, calm and distinctive. Full-bleed opaque square 1024x1024 final production artwork, straight-on, no mockup. No compass, no needle, no circle or compass ticks, no globe, no Safari resemblance, no blue/red palette, no sparkles or AI motifs, no text or wordmark, no gradients, no bevels, no glow, no shadows, no 3D, no texture, no outer border, no rounded-square icon mask baked in. This should feel like an independent designer's beautifully distilled browser mark.
